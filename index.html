Разбор на примере цепочек typedef и перечислений enum

2Разбор категорий типов в C++

2.1. Идентичные типы (Identical Types)

Ключевое слово typedef не создаёт новый тип данных, а лишь объявляет псевдоним (синоним) уже существующего. Компилятор определяет тип подстановкой базового определения.

Целочисленная группа T1T2T3T4T5intтип x
T2 → T1 → int  ·  T4 → T3 → int  ·  T5 → int
Все они — абсолютно один и тот же тип int.
Группа перечисления T6 T6T7T8
T7 → T6  ·  T8 → T6
Символьная группа T9T10char
T9 → char  ·  T10 → char
⚠ Правило перечислений (enum) Каждое новое объявление enum создаёт уникальный самостоятельный тип. Например, enum Color { Red, Green, Blue }; или enum bukva { … }; — тип, который не идентичен ни T6, ни другим перечислениям, даже если значения их элементов совпадают.

2.2. Совместимые типы (Compatible Types)

Совместимые — типы, значения которых можно неявно приводить или присваивать друг другу без ошибок компиляции.

  • Целочисленная группа: все псевдонимы int (T1–T5, тип переменной x) полностью взаимно совместимы.
  • Приведение enum: константы и переменные традиционных enum (T6–T8, y, z) неявно приводятся к int в выражениях и при присваивании.
  • Внутри одной группы перечисления: переменные T6, T7 и T8 взаимозаменяемы при присваивании и сравнении.
  • Символьная группа: T9, T10 и char полностью взаимозаменяемы.

2.3. Анонимные типы (Anonymous Types)

Анонимный тип — тип, объявленный «на лету» без собственного имени (идентификатора типа).

✗ Вариант 1: enum { Alfa, Beta, Gama, Delta } y; Это анонимный тип. У самого enum нет названия, поэтому объявить ещё одну переменную этого же типа в другом месте программы по имени типа невозможно.
✓ Вариант 2: enum bukva { Alfa, Beta, Gama, Delta } z; Анонимного типа здесь нет: перечислению присвоено имя bukva, значит, это именованный пользовательский тип.

3Ключевые правила системы типов C++

  • Псевдонимы. typedef — это просто «второе имя» типа. Для компилятора T1 и T4 — буквально одно и то же int.
  • Строгое разделение перечислений. Разные объявления enum — разные типы. Присвоить значение типа bukva переменной типа T6 напрямую (без явного приведения) нельзя.
  • Встроенные типы. Переменная int x; имеет обычный именованный базовый тип int. Анонимными бывают только структуры, объединения и перечисления, объявленные без имени.

4Шпаргалка для самопроверки

🔍 Видишь typedef?
Это не новый тип, а синоним существующего.
🔍 Видишь новый enum Name { … }?
Это новый уникальный тип, не идентичный другим enum.
🔍 Ищешь анонимный тип?
Ищи конструкции без имени типа: enum { … } …; или struct { … } …;.
